# Каталог льгот при приёме в 2026 году

Собран **06.09.2026** по официальным страницам приёмных комиссий и приложениям к правилам приёма.
Это каталог условий БВИ и 100 баллов, включая предметы, классы, степени дипломов,
образовательные программы, исключения и требования конкурсных групп.
Стоимость обучения, число мест, стипендии и баллы индивидуальных достижений в этот набор не входят.

Запись — строка условия или отдельная ячейка права/конкурсной группы, **не число уникальных
олимпиад и не число гарантированно доступных поступлений**. Одна запись может содержать
несколько направлений, предметов или обе льготы. Международные олимпиады вынесены отдельно
только там, где источник содержит самостоятельную матрицу условий; остальные условия остаются

В приложениях МГТУ правила приёма **2026** содержат отдельные таблицы для олимпиад
**2025/26 и 2024/25** годов. Это действующие условия для дипломов разных лет;
поле `olympiad_year` сохраняет эту разницу. ВУЗовские правила 2027 года не подменяются правилами 2026.

## Файлы

- `snapshots/2026/catalog.json` — каталог, пригодный для загрузки и поиска.
- `snapshots/2026/coverage.json` — количества записей по вузам и категориям.
- `snapshots/2026/source_manifest.json` — 94 URL, итоговые URL после перенаправлений, SHA-256 и время получения.
- `snapshots/2026/sources/` — оригинальные PDF/HTML и JSON с полным извлечённым текстом,
  таблицами, объединениями HTML-ячеек и номерами страниц.
- `snapshots/2026/hse_programs.json` — соответствие программ ВШЭ кодам направлений и документам.
- `snapshots/2026/programs.json` — дополнительный справочник 30 программ МФТИ по 10 направлениям: физтех-школа, конкурсная группа, источник и строки исходной таблицы. Используется веб-клиентом; SQLite/SQL-загрузчик льгот по-прежнему загружает `catalog.json`.

Обновление справочника МФТИ (из директории `data_loader`):

```console
python -m admissions.sources mipt_places https://pk.mipt.ru/bachelor/2026_places/ mipt
python -m admissions.mipt_programs
```

Общий `python -m admissions build` также пересобирает `programs.json` из сохранённого
источника. Объединённые ячейки таблицы разворачиваются, повторные строки заказчиков
целевого обучения не создают дубликаты программ. Связь с льготами проходит через
физтех-школу и сохраняет ограничения конкретных конкурсных групп.

Оригиналы PDF включены в Git исключением из общего `*.pdf` в `.gitignore`.
SQLite и SQL-выгрузки генерируются локально, их не нужно хранить рядом с исходными данными.

## Запуск

Рабочая директория — `olympguide-static/data_loader`. Для проверки, поиска, SQLite и SQL
достаточно Python 3.10+ без сторонних библиотек:

```console
python -m admissions validate
python -m admissions search --university msal --text Кутафинская --limit 10
python -m admissions search --university mipt --benefit bvi --text ФПМИ
python -m admissions load --database admissions_2026.sqlite3
python -m admissions export-sql --output admissions_2026.sql
```

Загрузка в SQLite проверена: полное сохранение JSON, повторный запуск без дублей,
отказ от некорректного каталога до записи и сохранение других годов.

Для существующей PostgreSQL проекта выгрузка создаёт таблицы в схеме `olympguide`:

```console
psql --set ON_ERROR_STOP=1 --dbname YOUR_DATABASE --file admissions_2026.sql
```

SQL выполняется в одной транзакции. Повторный импорт заменяет только 2026 год
в трёх таблицах `admission_university`, `admission_source`, `admission_rule`.
В рабочую PostgreSQL экспорт в рамках подготовки набора не применялся;
проверены генерация SQL и эквивалентная загрузка в SQLite.

Пример чтения в PostgreSQL:

```sql
SELECT olympiad_name, olympiad_profile, program_scope, payload::jsonb AS conditions
FROM olympguide.admission_rule
WHERE admission_year = 2026 AND university_id = 'msal';
```

## Формат и совместимость с приложением

Каждая запись содержит `admission_year`, `university_id`, `category`, `benefit_types`,
`source_id`, `source_url`, `location`, `values` и `conditions`.
`location` указывает страницу/таблицу/строку/столбец либо пункт текстового документа.
`values` хранит именованные поля условия. Текстовые ограничения являются частью данных,
а не необязательными примечаниями. Каталог позволяет показывать и искать правила;
он не принимает автоматическое решение о наличии льготы у конкретного абитуриента.

Коды с «кроме», «за исключением», предметы через `/`, ограничения физтех-школ,
условия на степень диплома и специальные пороги нельзя разворачивать простым
декартовым произведением. Например, МФТИ содержит пороги 75, 80, 85 баллов и разные
правила для конкурсных групп; МИФИ допускает 8-й класс для 100 баллов; МГЮА различает
11-й класс (БВИ и 100 баллов) и 10-й (100 баллов) у Кутафинской олимпиады.

**Текущий Go API `/benefit` и iOS-клиент читают старые таблицы `benefit`,
`confirmation_subjects`, `fullscore_subjects`. Новые `admission_*` они пока не читают.**
Экспорт намеренно не преобразует записи в старую модель: она не хранит год/источник,
допускает классы только 9–11, выражает класс минимальным порогом, а уникальность не
различает БВИ и 100 баллов. Автоматическая загрузка туда исказила бы часть условий.
Для отображения нового каталога в приложении нужно подключить чтение `admission_rule`
либо расширить модель льгот и реализовать проверенное сопоставление программ/олимпиад.
Имена и номера олимпиад нельзя связывать с существующими ID по нечёткому совпадению.

В исторических загрузчиках дополнительно исправлены URL ИТМО, поле `score` вместо
`min_score`, селекторы новой страницы ВШЭ и побочное скачивание при импорте общего GET-клиента.
Код выгрузки ИТМО теперь запускается только из `main`, а не при импорте модуля.

## Повторное получение и пересборка

Для извлечения PDF/HTML нужны отдельные зависимости:

```console
python -m pip install -r admissions/requirements.txt
python -m admissions.fetch --help
```

Команда повторного скачивания запускается отдельным модулем:

```console
python -m admissions.fetch --output admissions/staging/2026 --university itmo
python -m admissions.fetch --output admissions/staging/2026
```

Она сохраняет источники в отдельную папку, сравнивает контрольные суммы и пишет
`fetch_report.json`. Зафиксированный снимок не перезаписывается. URL берутся из manifest:
для новой кампании необходимо заново проверить официальные страницы, новые приложения
и год внутри документов. Имя PDF само по себе не доказывает год: ИТМО перенаправляет
годовые ссылки на файлы без года; МИФИ публикует утверждённый документ с `proekt` в имени.

Пересборка из сохранённых оригиналов (сеть не требуется):

```console
python -m admissions.reextract
python -m admissions build
python -m admissions validate
python -m unittest discover -s admissions/tests -v
```

`admissions.collect` — вспомогательное обнаружение московских PDF ВШЭ, приложений МГТУ
и перечня МАИ по сохранённым посадочным страницам. Он заполняет отсутствующие файлы;
`--refresh` перезаписывает найденные документы. Для обычной сверки используйте `admissions.fetch`.

пороги МФТИ, классы МИФИ и МГЮА, загрузку без дублей и SQL-экранирование.
