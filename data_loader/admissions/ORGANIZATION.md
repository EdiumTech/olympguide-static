# Структура вузов и программы, приём 2026

Проверено 7 сентября 2026. Охват: ВШЭ Москва, ИТМО, основной каталог МГТУ,
МФТИ, МИФИ Москва, МАИ без филиалов, МГЮА. Это подразделения, связанные
с опубликованными программами, а не полный административный штат вузов.

`catalog.json`: 91 основное подразделение, 115 дочерних кафедр, 378 записей
программ / направлений. У программы может быть несколько `unit_ids`; у кафедры
есть `parent_id`. Код направления не определяет факультет. Связи
`affiliations` содержат официальный источник и место в нём. `sources/`
хранит исходные HTML/JSON/PDF, URL, время получения и SHA-256.

## Источники и особенности

- **ВШЭ:** официальный каталог `https://www.hse.ru/n/education/bachelor?campus=51999662&pageSize=100`,
  79 позиций. Сохранены выборки всех 21 московского подразделения из фильтра
  `unit`. Проверяется, что все страницы загружены полностью. Для двух вторичных
  кодов («Реклама и связи с общественностью», «Экономика и анализ данных»)
  фильтр подразделения пропускает позицию, хотя полный каталог связывает её
  с той же программой по точному названию и URL. Эта связь сохранена отдельно
  с соответствующим локатором; правила разных кодов не объединяются.
  Шесть проверенных различий названий (ЦПМ, пометки онлайн/английского языка)
  перечислены явно в `organization_build.py`; код направления обязателен для совпадения.
- **ИТМО:** API `https://abitlk.itmo.ru/api/v1/programs/short` с `degree=bachelor`,
  `limit=100`, `page=1` и 27 HTML-страниц программ на `abit.itmo.ru/program/bachelor/`.
  Каждая группа API проверяется на `year=2026`. 27 программ дают 37 сочетаний
  «программа — направление», связанных с 17 факультетами, институтами, школой и центрами.
- **МГТУ:** публичный API основного сайта
  `https://api.www.bmstu.ru/majors/baccalaureate-and-specialty?offset=0&limit=200`.
  Ответ содержит факультеты и кафедры каждой программы. 53 строки дают 54 кода:
  совместная строка 40.05.03 / 40.05.01 разделяется на две явные позиции.
  Названия профилей в этом ответе отсутствуют: записи имеют `directory_kind=field`.
  Кафедра ЮР сохраняется кафедрой, хотя API помещает её в массив faculties.
- **МФТИ:** таблица мест `https://pk.mipt.ru/bachelor/2026_places/` и разделы школ
  `https://pk.mipt.ru/bachelor/2026_rules/`. 30 программ, 12 школ. ФБМФ и ВШБИ
  разнесены по метке в названии конкретной программы; объединённая область действия
  исходной льготы остаётся «ФБМФ/ ВШБИ». Идентификаторы ранее собранных программ сохранены.
- **МИФИ:** обе таблицы бакалавриата и специалитета
  `https://admission.mephi.ru/admission/baccalaureate-and-specialty/education/programs`.
  Объединённые ячейки разворачиваются с сохранением исходной строки.
  82 программы, 34 направления, 9 институтов/факультетов. Упоминание 10.05.05
  в документе о льготах не подменяет отсутствующее подтверждение набора 2026:
  дополнительная запись видна отдельно без привязки к подразделению.
- **МАИ:** `https://priem.mai.ru/foreign-applicants/bachelor/programs/` содержит
  текущую таблицу программ 2026 с названиями институтов и кафедрами. Сопоставляются
  явные ключи подразделений `data-fac` с их официальными страницами
  `https://institutes.mai.ru/`; номера кафедр сами по себе не используются для
  определения института. Филиалы strela/stupino/voshod/vzlet исключены.
  83 программы в 12 подразделениях; в каталог входит Передовая инженерная школа.
- **МГЮА:** двухстраничная «Памятка по направлениям подготовки и специальностям
  на 2026–2027 учебный год», опубликованная на странице приёмной кампании:
  `https://msal.ru/upload/iblock/9ad/gzmrdfmcl73ka9c8yhe1wg20wp6qwqk6.pdf`.
  13 профилей/специализаций, 8 институтов/школ. Индивидуальные образовательные
  траектории сохранены внутри профиля. Варианты на базе высшего образования
  имеют отдельную пометку и не смешиваются с обычным бакалавриатом.

Подразделение и связанное направление не означают безусловное предоставление
всех льгот. Веб-клиент сохраняет исходные области действия и условия подтверждения.
Программы без найденных правил льгот остаются видимыми.

## Воспроизведение

Файлы `catalog.json` и `sources/`, описанные выше, находятся внутри локальной
папки `snapshots/2026/organization/`. Первоначальный набор скачивается из
GitHub Release командой `python -m admissions download`.

Из `olympguide-static/data_loader` (на macOS заменить python на python3):

```console
python -m pip install -r admissions/requirements.txt
python -m admissions.organization_build
python -m admissions.organization --validate
```

Сборка читает сохранённые оригиналы и извлечение PDF, без сети. Общая команда
`python -m admissions build` также пересобирает этот справочник после таблицы МФТИ.
Веб-просмотр и проверка готового справочника не требуют сторонних пакетов.

Обновление закреплённых официальных URL выполняется явно:

```console
python -m admissions.organization --refresh
python -m admissions.organization_build
python -m admissions.organization --validate
```

Если поменялся набор программ/подразделений, требуется обновить перечень источников:
проверки полноты останавливают сборку при несовпадении. Новую страницу можно сохранить:
`python -m admissions.organization source_key university_id URL`.
После обновления PDF пересоздайте таблицы командой
`python -m admissions.organization --extract-pdf` и проверьте обе страницы визуально.
Извлечение связано с SHA-256 PDF: устаревшие таблицы не принимаются сборщиком.

После пересборки перезапустите `python web/server.py` из корня репозитория.
Этот справочник читает веб-клиент. Старый Go API и его таблицы факультетов не изменены;
команды `admissions load/export-sql` по-прежнему загружают каталог условий льгот.
