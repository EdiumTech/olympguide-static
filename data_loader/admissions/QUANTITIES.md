# Стоимость и места, приём 2026

Дополнение к основному каталогу: `releases/2026-quantities.json` закрепляет архив
GitHub Release и SHA-256 каждого файла. JSON с числами, HTML и PDF находятся в
архиве, а не в Git. Исходный набор льгот `releases/2026.json` не изменяется.

```console
python -m data_loader.admissions download
python -m data_loader.admissions download-quantities
python web/server.py
```

Проверенный охват на 8 сентября 2026 года:

| Вуз | Записей | Бюджетные места | Платные места | Стоимость |
|---|---:|---:|---:|---:|
| ВШЭ | 79 | 79 | 79 | 74 |
| ИТМО | 37 | 37 | 37 | 36 |
| МГТУ | 54 | 54 | 54 | 54 |
| МФТИ | 30 | 30 | 30 | 30 |
| МИФИ | 83 | 76 | 69 | 77 |
| МАИ | 83 | 83 | 83 | 83 |
| МГЮА | 13 | 13 | 13 | 13 |
| **Всего** | **379** | **372** | **365** | **367** |

Это число записей с подтверждённым показателем, а не сумма мест. Места на общую
конкурсную группу повторяются у её профилей с одинаковым `group_id`.
Суммирование таких записей завысит план набора. `budget_places` включает квоты,
`paid_places` — план платного набора, оба показателя не являются числом вакансий.

По умолчанию рассматриваются первый курс и очная форма. У двух программ МГЮА
на базе высшего образования указана заочная форма; очно-заочный тариф приведён
в примечании. Скидки за баллы ЕГЭ не вычитаются из базовой стоимости.
Для российских программ ИТМО не включены отдельные платные места иностранцев.
У МГЮА платные места включают иностранцев и второе высшее, как указано в документе.

`cost_period=year` означает год, `semester` — семестр. Тарифы МИФИ относятся к
осеннему семестру 2026/2027. Они не умножаются на два: цена следующего семестра
этим приказом не устанавливается. У каждой известной величины в
`quantity_evidence` сохранены URL, идентификатор источника, строка/страница,
область применения и идентификатор общей группы.

## Исключения и пробелы

- ВШЭ, «Вычислительные социальные науки»: пять кодов относятся к внутреннему
  отбору после зачисления на базовую программу. Общий отбор — 30 бюджетных и
  10 платных мест; отдельный тариф не опубликован, скидка базовой программы
  сохраняется. Это не самостоятельный конкурс абитуриентов.
- ИТМО, AI360: 36 бюджетных, платного набора нет. Цена отсутствует, а не равна нулю.
- МИФИ: для восьми экономических профилей цена есть в приложении 1 к приказу
  №155/8 (страницы 7 и 9), но платные места отсутствуют в опубликованном плане.
  Для 03.05.02 не найден бюджетный план. Старые числа с карточек программ
  не подставляются под 2026 год.
- Шесть записей МИФИ относятся к совместным/обнинским программам, объединённой
  карточке двух кампусов или направлению 10.05.05, упомянутому только в льготах.
  Для них нет подтверждённого полного соответствия московскому набору и тарифу.

Неизвестные показатели остаются `null` с пояснением. Нулевое число бюджетных мест
МАИ подтверждено также карточкой программы, где указана только платная основа.

## Пересборка и проверка

Загрузка и веб-просмотр используют стандартную библиотеку Python. Для сборщика:

```console
python -m pip install -r data_loader/admissions/requirements.txt
python -m data_loader.admissions.quantities_build
python -m data_loader.admissions.quantities_release
```

`quantities_build` использует сохранённые страницы. Интерпретации PDF МГЮА,
приказов МИФИ и тарифа МФТИ привязаны в `REVIEWED` к проверенным SHA-256; изменение
этих документов требует повторной сверки, а не молчаливого переноса старых чисел.
При проверке МГЮА надстрочные номера сносок исключены из чисел целевой квоты;
общее число бюджетных мест получено сложением общего конкурса и трёх квот.

Отдельный источник можно обновить командой
`python -m data_loader.admissions.quantities SOURCE_ID UNIVERSITY URL`.
Для МАИ сборщик поддерживает аргумент Python `ca_bundle` функции `fetch`:
проверка TLS выполняется с официальным корневым сертификатом Минцифры,
полученным по HTTPS с `gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt`.
Проверка сертификатов не отключается и доверие системы не изменяется.

Тесты запускаются из `data_loader`: `python -m unittest discover -s admissions/tests`.
В backend: `python deploy/import_admissions.py --static-repo ../olympguide-static
--quantities-only --host <IP>` создаёт резервную копию и обновляет показатели
транзакционно, сохраняя идентификаторы и льготы. Проверка публичного API:
`python deploy/verify_quantities.py --static-repo ../olympguide-static`.
