# Каталог РСОШ 2026/2027 и исправления карточек

Проверено 8 сентября 2026. [РСОШ](https://rsr-olymp.ru/news/123) ссылается на
[проект приказа № 170112](https://regulation.gov.ru/projects/170112/).
В карточке проекта этап «Принятый документ» пуст; опубликованный файл — проект
от 10 августа. Не называем перечень утверждённым.

В каталоге 79 олимпиад, 303 строки профилей. Каждая строка содержит название,
профиль, предметы/группы направлений и уровень I–III. У НТО состав профилей
изменился: старый составной профиль «беспилотный транспорт…» не перенесён.
Степень I–III диплома и уровень I–III олимпиады — разные поля.

`academic_year=2026/2027` не означает `admission_year=2027`. Новые записи не
получают правил поступления 2026; отсутствие проверенных правил показывается
как недостаток данных. Исторические ID, избранное, дипломы и страницы старых
условий сохраняются. Номера строк и уровни не входят в ключ профиля: их
исправление не создаёт дубликат. Изменившееся название/профиль требует отдельной
проверки соответствия, без автоматического переноса дипломов.

## Загрузка и проверка

```sh
python -m data_loader.admissions.rsosh download
python -m data_loader.admissions.rsosh validate
python -m data_loader.admissions.rsosh export-sql --output .private/rsosh.sql
```

Для воспроизводимого сбора доступны `build` и `package`. Парсер читает таблицу
из официального DOCX, проверяет продолжения объединённых строк и отказывает
при недостающем профиле, уровне, номере или изменении состава документа.
В Git находятся код и манифест `releases/rsosh-2026-2027.json`; JSON и исходный
DOCX находятся в ZIP GitHub Release. Загрузчик проверяет SHA-256 каждого файла
и не заменяет изменённую локальную копию. Переход к утверждённому перечню
требует нового проверенного источника, манифеста и изменения статуса.

В том же архиве сохранены проверенные контакты приёмных комиссий семи вузов,
с источником, датой проверки и областью действия. Например, для основного
кампуса МГТУ — `abiturient@bmstu.ru`. Контакты филиалов не подставляются вместо
контактов основного кампуса. Повторный импорт базового каталога не стирает
почту; импорт реестра обновляет её только по проверенному набору контактов.

## Интерфейсы

- В iOS убраны звёздочки возле мест, год и служебные примечания под стоимостью;
  неизвестные величины остаются неизвестными, цена за семестр не становится
  ценой за год. Карточки льгот снова используют компактную прежнюю компоновку.
- Ссылки в заголовках имеют названия «Сайт вуза» и «Страница программы».
  Адрес ссылки хранится отдельно; пустая почта не оставляет один значок `@`.
- Стипендии открываются кнопкой «Стипендии и поддержка» в верхней части страницы
  вуза. В карточке программы кнопка находится перед сведениями о программе;
  из ограниченной выборки можно открыть все выплаты вуза.
- Направления без программ не возвращаются в общем API-каталоге; прямой
  переход в пустое направление показывает понятное сообщение.
- Вузы на странице олимпиады возвращаются только при наличии связи правила
  с программой. Пустой результат фильтра не оставляет один раскрытый заголовок.
- Веб-каталог содержит только новый перечень; ссылки из старых условий
  продолжают открывать исторические страницы. Статус проекта показан отдельно.
- Связь общего календаря «Высшей пробы» 2026/2027 с новыми ID добавляется
  только для этой проверенной коллекции и сезона. Даты, ревизии и личные
  отметки при этом не меняются. Это не связь с правилами поступления.

## Проверки

42 Python-теста загрузчиков/данных, включая повторный импорт в PostgreSQL,
сохранность ID, избранного и отметок календаря, подмену архива, полноту профилей
и разделение годов; 17 тестов веб-проекций/HTTP; 11 проверок дат в JavaScript.
В backend: `go test ./...`, `go vet ./...`, интеграционные проверки пустых
каталогов, связей вуз–программа, фильтров нового сезона и исторических ID.
В браузере проверены контакты, открытие стипендий, профиль НТО, переходы и
карточка программы. Swift-файлы проверены синтаксическим парсером относительно
базы; **Xcode отсутствует, сборка iOS и Swift-тесты не запускались**.

Суммы стипендий этой правкой не пересматривались. В частности, размер выплат
МГТУ на 2026/2027 остаётся неподтверждённым и показывается без числовой суммы.
