# ОлимпГид в браузере

Веб-клиент для просмотра собранных данных на Windows, macOS и Linux.
Работает с каталогом приёма 2026 из `data_loader/admissions/snapshots/2026`.
Для запуска достаточно **Python 3.10+**. Установка пакетов, Node.js, Docker,
учётная запись и подключение к PostgreSQL не нужны.

Из корня `olympguide-static`:

```console
python -m data_loader.admissions download
python web/server.py
```

На macOS обычно используется `python3 web/server.py`.
Откройте **http://127.0.0.1:8765** в Chrome, Safari, Edge или Firefox.
Оставьте терминал с сервером открытым; для остановки нажмите Ctrl+C.
Если порт занят: `python web/server.py --port 8766`.
Первая команда загружает закреплённый архив из GitHub Release и проверяет SHA-256
всех файлов. Повторная загрузка не нужна. Для просмотра на другом компьютере
клонируйте репозиторий и выполните обе команды; после загрузки сеть не требуется.

## Страницы и возможности

- `/universities` — вузы, поиск по названию/городу, фильтры города и льготы.
- `/universities/hse` — вуз, его программы, группы направлений и условия льгот.
- `/units/<id>` — факультет, институт, школа или кафедра; направления с программами и льготы подразделения.
- `/olympiads` — олимпиады, поиск по названию/профилю, фильтры вуза, категории и льготы.
- `/olympiads/<id>` — олимпиада, профили, уровни, вузы и условия применения диплома.
- `/fields` — направления из официальных каталогов программ и условий льгот, поиск по коду и названию.
- `/fields/01.03.02` — направление, программы в разных вузах и условия льгот.
- `/fields/09.03.01?unit=bmstu-iu` — направление внутри выбранного факультета; контекст сохраняется при переходе к программе.
- `/programs/<id>` — программа, направление в конкретном вузе или группа условий.
- `/favorites` — избранные вузы, олимпиады и программы, сохраняются в этом браузере.

Условие содержит БВИ/100 баллов, профиль, диплом, классы, подтверждающий предмет,
баллы, год олимпиады и полную исходную формулировку. Доступны ссылка на сайт вуза
и локальная копия документа, для PDF — с номером страницы. Фильтры и страницы
сохраняются в URL, работают обновление страницы и кнопки «назад/вперёд».
Интерфейс адаптируется к широкому экрану и узкой панели браузера.

## Как связаны данные

Каталог целиком сохраняется без изменения: каждая исходная запись доступна в UI.
Названия олимпиад объединяются внутри категории по регистру, пробелам, пунктуации
и `е/ё`; нечёткое сопоставление разных названий не используется. Исходные названия
остаются в записях и доступны поиску.

67 программ ВШЭ из таблиц льгот имеют явное соответствие коду направления. Строки ВсОШ с точно
совпадающим названием программы и единственным кодом объединяются с её строками РСОШ.
Одинаковые названия при разных кодах не объединяются. Для других вузов
список кодов без оговорок разбивается на направления. Названия кодов взяты из
существующего справочника backend; копия с происхождением хранится в `data/fields.json`.

Для МФТИ дополнительно используется `snapshots/2026/programs.json`: **10 направлений,
30 программ** из официальной таблицы набора 2026. Сохраняются физтех-школа, конкурсная
группа, строка и ссылка на источник. Название программы и код направления хранятся
независимо от таблицы льгот, поэтому отсутствие кода в таблице льгот не скрывает программу.
На странице программы МФТИ доступны условия её школы. Такие связи помечены
`school_conditions` и `related_program_ids`: принадлежность к школе не означает
автоматического предоставления всех её льгот. Полная формулировка видна сразу;
общие условия 100 баллов доступны отдельной ссылкой. Числа мест не присваиваются
отдельным программам из общей конкурсной группы.

**Условия «все, кроме…», альтернативные перечни и исходные условия школ остаются группами.**
Они не добавляются автоматически ко всем направлениям и не теряются: смотрите блок
«Группы направлений и общие условия» или вкладку «Льготы» на странице вуза.
Каталог направлений включает официальные перечни программ; отсутствие льгот не скрывает
программу. Данных о стоимости и местах здесь нет. Сайт не вычисляет персональную
гарантию поступления и не скрывает исключения из исходных документов.

Избранное не синхронизируется с iOS: это отдельный браузерный просмотр текущего
набора, с теми же основными переходами «вуз → программа → олимпиады» и
«олимпиада → вузы/направления → условия». Старый Go API не требуется.

## Устройство и проверка

`server.py` — HTTP-сервер только для чтения на loopback-адресе.
`catalog.py` строит индексы из JSON; `/api/catalog` отдаёт справочники,
`/api/rules` — отфильтрованные условия с пагинацией. Браузер получает компактный
индекс, а не весь многомегабайтный каталог. `static/` — HTML/CSS/JavaScript без
внешних библиотек, шрифтов, аналитики и запросов к сторонним сервисам при просмотре.

```console
python -m unittest discover -s web/tests -v
```

Проверки: сохранность записей и ссылок, исключения из области действия, связь
ВсОШ/РСОШ с программой ВШЭ, совместные фильтры, пагинация, прямые ссылки, PDF,
границы доступных файлов. После обновления `catalog.json` перезапустите сервер.
Можно выбрать другой совместимый снимок: `python web/server.py --catalog PATH`.
Справочник программ берётся рядом с выбранным снимком и проверяется на совпадение года.

## Факультеты, институты, школы и кафедры

По умолчанию страница вуза открывает подразделения. На странице подразделения
программы сгруппированы по направлению. Одно направление может принадлежать нескольким
подразделениям. На странице программы доступны ссылки на все её подразделения,
кафедры (где опубликованы), траектории МГЮА и сохранённые источники распределения.

`snapshots/2026/organization/catalog.json` содержит **91 основное подразделение,
115 кафедр и 378 записей программ / направлений**. Для МГТУ каталог описывает направления
с факультетами и кафедрами; отдельные названия профилей за него не придумываются.

| Вуз | Основные подразделения | Записи программ / направлений |
|---|---:|---:|
| ВШЭ, Москва | 21 | 79 |
| ИТМО | 17 | 37 (27 программ по кодам направлений) |
| МГТУ, основной каталог | 12 | 54 |
| МФТИ | 12 | 30 |
| МИФИ, Москва | 9 | 82 |
| МАИ, головной вуз | 12 | 83 |
| МГЮА | 8 | 13 |

Полные правила льгот остаются в исходном каталоге. Для новых программ связь
`field_conditions` ведёт к условиям явно перечисленного направления. Для МФТИ
сохраняется `school_conditions`. Совпадение института само по себе не распространяет
льготу на все его программы. `/api/rules?unit=<id>` фильтрует исходные правила,
связанные с программами подразделения, сохраняя оговорки.

В документе о льготах МИФИ есть 10.05.05, отсутствующее в опубликованном перечне
программ приёма 2026. Эта дополнительная запись сохранена без неподтверждённой
привязки к институту и отмечена в интерфейсе. Это не доказательство текущего набора.

Сбор, проверка и воспроизведение описаны в
`data_loader/admissions/ORGANIZATION.md`.
