# ОлимпГид

iOS-приложение и данные о вузах, олимпиадах и льготах при поступлении.

## Посмотреть данные на компьютере

Из корня репозитория:

```console
python web/server.py
```

На macOS: `python3 web/server.py`. Откройте http://127.0.0.1:8765.
Нужен только Python 3.10+, без установки зависимостей и настройки базы данных.

В браузере доступны вузы, олимпиады, направления и программы с условиями льгот,
поиск, фильтры, избранное и официальные документы.
Подробнее: [запуск и устройство веб-клиента](web/README.md).

## Структура

- `iOS/` — основной мобильный клиент.
- `web/` — просмотр собранных данных в браузере на ПК и Mac.
- `data_loader/admissions/` — каталог приёма 2026, источники, сбор и загрузка.
- [Документация данных](data_loader/admissions/README.md).
